调试参数

所有参数默认 NULL，直接输入内容会自动解除 NULL，清空后恢复 NULL。INOUT 填写初始值；OUT（包括游标）保持只读 NULL。文本无需 SQL 引号；需要空字符串时可手动取消 NULL。执行完成后显示返回值和游标结果集。

粘贴调用文本

粘贴 DECLARE…BEGIN…END; 或 CALL 调用，自动识别过程、赋值和参数顺序。支持字符串、数字、NULL、已声明变量和命名参数。解析后打开参数窗口供检查，再点击“开始调试”执行。
